# QUEM É O IMPOSTOR? — Site instalável (PWA)

## Arquivos
- `index.html`: jogo completo.
- `manifest.webmanifest`: configuração para adicionar à tela inicial.
- `sw.js`: cache para abrir offline depois da primeira visita.
- `icon.svg`: ícone.

## Publicar gratuitamente com GitHub Pages
1. Entre/crie uma conta em https://github.com
2. Crie um repositório público, por exemplo `quem-e-o-impostor`.
3. Envie os quatro arquivos desta pasta para a raiz do repositório.
4. Em Settings → Pages, escolha publicar a partir da branch `main`, pasta `/ (root)`.
5. Aguarde a publicação. O GitHub mostrará o endereço do site.

## Instalar no Android
1. Abra o link publicado no Chrome.
2. Abra o menu ⋮ e toque em **Adicionar à tela inicial** ou **Instalar app**, se aparecer.
3. Depois da primeira abertura, o jogo pode ser carregado offline pelo cache do navegador.

## Observações
- O jogo é presencial e roda localmente no dispositivo; não envia nomes nem votos para um servidor.
- A publicação requer internet. O modo offline depende de o site ter sido carregado uma primeira vez e de o navegador manter o cache.
